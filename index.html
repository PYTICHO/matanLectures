// Лекция 01
Основные понятия теории вероятностей
Типы событий, операции над ними, определения вероятности и комбинаторика.
Типы событий

Любой опыт — осуществление комплекса условий S. Результаты делятся на три типа:

  • Случайное событие А — может произойти или нет.
  • Невозможное (Ø) — точно не произойдёт.
  • Достоверное (Ω) — точно произойдёт.
Операции над событиями
  • АВ (произведение) — оба А и В одновременно.
  • А+В (сумма) — хотя бы одно из А или В.
  • Ā (дополнение) — противоположное А: А+Ā=Ω, АĀ=Ø.
  • А⊂В — А влечёт В.
  • Несовместные: АВ=Ø.

Законы: коммутативный, ассоциативный, дистрибутивный. Формулы де Моргана: Ā+B̄ = A̅B̅, ĀB̄ = A̅+B̅.

Определения вероятности

Классическое: применимо, когда элементарные исходы равновозможны и конечны.

Статистическое: вероятность ≈ относительная частота при большом числе опытов W_A = m/n.

Геометрическое: отношение площадей (длин/объёмов) при бесконечном числе исходов.

Аксиоматическое (Колмогоров): P(A)≥0, P(Ω)=1, для несовместных — P(A+B)=P(A)+P(B).

// Пример — классическое
Кубик: P(чётное) = 3/6 = 1/2. P(>4) = 2/6 = 1/3.
Комбинаторика
  • Перестановки Pn = n! — все n элементов в разном порядке.
  • Размещения A(n,m) = n!/(n-m)! — выбор m из n с учётом порядка.
  • Сочетания C(n,m) = n!/[m!(n-m)!] — выбор m из n без учёта порядка.
// Урновая схема
Урна: N шаров, M первого типа. Берём n штук. Вероятность получить m первого типа: P = C(M,m)·C(N-M,n-m) / C(N,n).
Опыт / испытание
Осуществление комплекса условий S, при которых наблюдается случайное явление.
Случайное событие
Явление, которое при данном опыте может произойти или нет.
Обозначение: A, B, C …
Невозможное событие
Явление, которое не может произойти при данном опыте.
Обозначение: Ø
Достоверное событие
Явление, которое обязательно произойдёт при данном опыте.
Обозначение: Ω
Элементарный исход
Неделимый результат опыта; все элементарные исходы образуют пространство W.
ωᵢ ∈ W = {ω₁, ω₂, ...}
Полная группа событий
Множество попарно несовместных событий, в сумме дающих достоверное событие.
A₁+A₂+...+Aₙ = Ω, AᵢAⱼ = Ø
Перестановки (Pn)
Упорядоченные комбинации из всех n элементов.
Pn = n!
Размещения A(n,m)
Упорядоченный выбор m из n элементов. Порядок важен.
A(n,m) = n!/(n-m)!
Сочетания C(n,m)
Неупорядоченный выбор m из n элементов. Порядок не важен.
C(n,m) = n!/[m!(n-m)!]
Классическое определение вероятности
P(A) = m / n
m — число благоприятных исходов, n — общее число равновозможных исходов.
Геометрическая вероятность
P(A) = площадь(d) / площадь(D)
Для задач с бесконечным числом исходов. Аналогично для длин или объёмов.
Формулы де Моргана
Ā+B̄ = A̅B̅    и    ĀB̄ = A̅+B̅
Дополнение суммы = произведение дополнений. Дополнение произведения = сумма дополнений.
Комбинаторика
Pn = n!    A(n,m) = n!/(n-m)!    C(n,m) = n!/[m!(n-m)!]
Используй A(n,m) когда порядок важен, C(n,m) когда порядок не важен.
Свойства вероятности (аксиомы Колмогорова)
P(Ω)=1    P(Ø)=0    0≤P(A)≤1    P(Ā)=1-P(A)
Основные следствия аксиоматики.
Урновая схема
P = C(M,m) · C(N-M, n-m) / C(N, n)
N — всего шаров, M — первого типа, n — берём, m — нужно первого типа.
// Лекция 02
Теоремы сложения, умножения, Байеса
Условная вероятность, независимость событий, полная вероятность, формула Байеса.
Теоремы сложения

Несовместные события (АВ=Ø): P(A+B) = P(A)+P(B).

Совместные события: P(A+B) = P(A)+P(B)−P(AB) — из суммы убираем дважды посчитанное пересечение.

Следствие: P(Ā) = 1−P(A) — удобно считать вероятность через дополнение.

// Приём через дополнение
«Сумма двух кубиков больше 2» → P(Ā) = P(сумма=2) = 1/36, значит P(A) = 1−1/36 = 35/36.
Условная вероятность и теорема умножения

Условная вероятность: P(A/B) — вероятность A, при условии что B уже произошло. Пространство элементарных исходов сужается до WB.

Теорема умножения: P(AB) = P(A)·P(B/A) = P(B)·P(A/B).

Независимые события: A и B независимы, если P(A/B)=P(A). Тогда P(AB)=P(A)·P(B).

Независимость взаимна: если A независимо от B, то B независимо от A. Дополнения Ā, B̄ тоже независимы.

// С возвращением / без возвращения
Шары: с возвращением → независимые события. Без возвращения → зависимые, считаем условно.
Формула полной вероятности

Когда событие A наступает только при одной из гипотез H₁,…,Hₙ (образующих полную группу):

P(A) = Σ P(Hᵢ)·P(A/Hᵢ)

// Когда применять
Есть несколько «сценариев» (гипотез), каждый с известной вероятностью → суммируем вклад каждого в событие A.
Формула Байеса — «переоценка гипотез»

После того как событие A наступило, обновляем вероятность каждой гипотезы:

P(Hᵢ/A) = P(Hᵢ)·P(A/Hᵢ) / P(A)

P(A) вычисляется по формуле полной вероятности. Применяется в байесовских классификаторах (фильтрация спама).

Условная вероятность
Вероятность события A при дополнительном условии, что событие B уже произошло.
P(A/B) = P(AB) / P(B)
Независимые события
События A и B, где наступление одного не меняет вероятность другого.
P(A/B)=P(A) → P(AB)=P(A)·P(B)
Гипотезы (H₁,…,Hₙ)
Попарно несовместные события, образующие полную группу, при которых может произойти A. Вероятности заранее известны.
Теорема сложения (несовместные)
P(A+B) = P(A) + P(B)     [AB=Ø]
Теорема сложения (совместные)
P(A+B) = P(A) + P(B) − P(AB)
Условная вероятность
P(A/B) = P(AB) / P(B)
Теорема умножения
P(AB) = P(A) · P(B/A) = P(B) · P(A/B)
Для независимых: P(AB) = P(A) · P(B)
Полная вероятность
P(A) = Σᵢ P(Hᵢ) · P(A/Hᵢ)
Формула Байеса
P(Hᵢ/A) = P(Hᵢ)·P(A/Hᵢ) / P(A)
P(A) из формулы полной вероятности. Обновляет вероятности гипотез после наступления A.
// Лекция 03
Схема Бернулли и асимптотические формулы
Повторные независимые испытания: формула Бернулли, Муавра–Лапласа, Пуассона.
Схема Бернулли

n независимых испытаний, в каждом вероятность «успеха» p одинакова, q=1-p — «неудача».

Ключевой вопрос: с какой вероятностью успех произойдёт ровно m раз из n?

// Пример
Монета 5 раз. P(герб 3 раза) = C(5,3)·(0.5)³·(0.5)² = 10/32 ≈ 0.3125.
Когда какую формулу применять
  • Формула Бернулли — точная, при любых n. Вычислительно неудобна при больших n.
  • Локальная теорема Муавра–Лапласа — при больших n, p близко к 0.5. Точечная вероятность Pn(m).
  • Интегральная теорема Муавра–Лапласа — при больших n. Вероятность попадания m в интервал [k₁,k₂].
  • Теорема Пуассона — при малых p (≤0.1) и больших n. λ=np≈const.
// Пример — Пуассон
Брак p=0.005, n=1000. λ=5. P(8 бракованных) = e⁻⁵·5⁸/8! ≈ 0.0653.
Закон больших чисел (следствие)

Относительная частота (m/n) стремится к p при увеличении числа испытаний:

P(|m/n − p| ≤ δ) ≈ 2Φ(δ√(n/pq))

Функция Лапласа Φ(x) — табличная нечётная функция, Φ(x)→0.5 при x→∞.

Схема Бернулли
Конечная последовательность независимых испытаний с постоянной вероятностью успеха p в каждом.
Функция Лапласа Φ(x)
Нечётная табличная функция. Φ(x)→0.5 при x→∞. Используется для интегральной теоремы.
Φ(-x) = -Φ(x)
Малая функция Лапласа φ(x)
Чётная табличная функция для локальной теоремы. φ(x)→0 при x→∞.
φ(-x) = φ(x)
Параметр Пуассона λ
Среднее число успехов. При малом p и большом n: λ = np ≈ const.
Формула Бернулли (точная)
Pn(m) = C(n,m) · pᵐ · qⁿ⁻ᵐ
p — вероятность успеха, q=1-p, m — число успехов, n — число испытаний.
Локальная теорема Муавра–Лапласа (большие n, p≈0.5)
Pn(m) ≈ φ(x) / √(npq)    x = (m-np)/√(npq)
φ(x) берётся из таблицы. Применять при np(1-p)≥9 условно.
Интегральная теорема Муавра–Лапласа
P(k₁≤m≤k₂) ≈ Φ(b) − Φ(a)
a=(k₁-np)/√(npq), b=(k₂-np)/√(npq). Φ — табличная функция Лапласа.
Формула Пуассона (p мал, n велик)
Pn(m) ≈ e⁻λ · λᵐ / m!    λ = np
Применять при p≤0.1 и λ≤9.
Отклонение частоты от вероятности
P(|m/n − p| ≤ δ) ≈ 2Φ(δ√(n/pq))
// Лекция 04А
Случайные величины и их характеристики
Дискретные СВ, законы распределения, ФРВ, математическое ожидание и дисперсия.
Случайная величина (СВ)

СВ ξ — числовая характеристика опыта, принимающая значения случайно. Обозначают: ξ, η, ζ; их значения — xᵢ.

Дискретная СВ — конечное или счётное число значений. Задаётся таблицей {xᵢ, pᵢ} или формулой. Σpᵢ=1 обязательно.

Непрерывная СВ — значения заполняют интервал. Задаётся плотностью f(x).

ФРВ — функция распределения вероятностей

F(x) = P(ξ < x). Ключевые свойства:

  • 0 ≤ F(x) ≤ 1
  • Неубывающая
  • F(−∞) = 0, F(+∞) = 1
  • P(x₁ ≤ ξ < x₂) = F(x₂) − F(x₁)
  • Если F непрерывна: P(ξ=a) = 0 (для непрерывной СВ).
Числовые характеристики

Математическое ожидание M(ξ) — средневзвешенное значение. Для дискрет: M(ξ) = Σ xᵢpᵢ.

Дисперсия D(ξ) — мера разброса: D(ξ) = M(ξ²) − [M(ξ)]².

СКО σ(ξ) = √D(ξ) — в тех же единицах что ξ.

СВОЙСТВА M и D
  • P1 M(c) = c; M(cξ) = c·M(ξ)
  • P2 M(ξ+η) = M(ξ)+M(η)
  • P3 D(c) = 0; D(cξ) = c²·D(ξ)
  • P4 D(ξ+η) = D(ξ)+D(η) [если ξ,η независимы]
Случайная величина ξ
Функция ξ(ω) на пространстве элементарных исходов, принимающая числовые значения случайно.
Закон распределения
Совокупность значений СВ и вероятностей, с которыми она их принимает.
ФРВ F(x)
Вероятность того, что ξ примет значение строго меньше x.
F(x) = P(ξ < x)
Плотность вероятности f(x)
Для непрерывных СВ: производная ФРВ. P(a≤ξ≤b) = ∫ₐᵇ f(x)dx. ∫f(x)dx = 1.
Математическое ожидание M(ξ)
Среднее значение СВ с учётом вероятностей. Центр «тяжести» распределения.
Дисперсия D(ξ)
Средний квадрат отклонения от математического ожидания.
D(ξ) = M(ξ²) − [M(ξ)]²
СКО σ(ξ)
Среднеквадратическое отклонение. В тех же единицах что и ξ.
σ = √D(ξ)
Математическое ожидание (дискретная СВ)
M(ξ) = Σ xᵢ · pᵢ
Математическое ожидание (непрерывная СВ)
M(ξ) = ∫₋∞⁺∞ x · f(x) dx
Дисперсия (удобная формула)
D(ξ) = M(ξ²) − [M(ξ)]²
Дискретно: M(ξ²) = Σ xᵢ²·pᵢ. Непрерывно: M(ξ²) = ∫x²f(x)dx.
Вероятность попадания в интервал (непрерывная)
P(a ≤ ξ ≤ b) = F(b) − F(a) = ∫ₐᵇ f(x) dx
// Лекция 04Б
Основные виды непрерывных распределений
Равномерное, показательное и нормальное распределения — формулы и свойства.
Равномерное распределение ξ~U(a,b)

Плотность постоянна на [a,b]: f(x) = 1/(b-a). Все значения равновероятны.

M(ξ) = (a+b)/2. D(ξ) = (b-a)²/12.

// Применение
Минутная стрелка: отклонение ξ ~ U(0,60). P(ξ≤20) = 20/60 = 1/3.
Показательное (экспоненциальное) распределение ξ~Exp(λ)

f(x) = λe^(−λx) при x≥0, f(x)=0 при x<0. λ>0 — интенсивность.

M(ξ) = 1/λ. D(ξ) = 1/λ². Применяется для времени безотказной работы.

Свойство отсутствия памяти: прибор «не стареет» — вероятность отказа не зависит от уже отработанного времени.

Нормальное распределение ξ~N(a,σ)

Кривая Гаусса: симметрична относительно x=a. a — математическое ожидание, σ — СКО.

M(ξ)=a, D(ξ)=σ². График — «колокол», максимум при x=a.

Правило трёх сигм: P(|ξ−a|<3σ) ≈ 0.9973 — почти все значения в интервале (a-3σ, a+3σ).

Вероятность попадания: P(a₁<ξ<a₂) = Φ((a₂-a)/σ) − Φ((a₁-a)/σ).

// Стандартное нормальное N(0,1)
При a=0, σ=1: P(-x₀<ξ<x₀) = 2Φ(x₀). Φ(x) — табличная функция Лапласа.
Равномерное U(a,b)
Постоянная плотность на отрезке [a,b]. Все значения равновероятны.
f(x) = 1/(b-a) на [a,b]
Показательное Exp(λ)
Моделирует время ожидания или работы без отказов. Обладает свойством отсутствия памяти.
f(x) = λe^(-λx), x≥0
Нормальное N(a, σ)
Наиболее важное распределение: сумма многих независимых СВ стремится к нормальному (ЦПТ).
ξ ~ N(a, σ) → M=a, D=σ²
Кривая Гаусса
График плотности нормального распределения. «Колокол» с максимумом в точке x=a, симметричный относительно a.
Равномерное U(a,b)
f(x) = 1/(b-a)   M = (a+b)/2   D = (b-a)²/12
Показательное Exp(λ)
f(x) = λe^(-λx)   M = 1/λ   D = 1/λ²
Нормальное N(a,σ) — плотность
f(x) = 1/(σ√(2π)) · exp[−(x-a)²/(2σ²)]
Нормальное — вероятность попадания в интервал
P(a₁<ξ<a₂) = Φ((a₂-a)/σ) − Φ((a₁-a)/σ)
Φ(x) — функция Лапласа из таблицы. Φ(-x) = -Φ(x).
Правило трёх сигм
P(|ξ−a| < kσ): k=1→0.6827   k=2→0.9545   k=3→0.9973
// Лекция 05
Предельные теоремы
Центральная предельная теорема: сумма независимых СВ стремится к нормальному закону.
Центральная предельная теорема (ЦПТ)

ξ₁, ξ₂, …, ξn — независимые одинаково распределённые СВ с M(ξᵢ)=a и D(ξᵢ)=σ²≠0.

Тогда при больших n их сумма ξ = Σξᵢ распределена приближённо нормально:

ξ ~ N(na, σ√n)

Это объясняет, почему нормальное распределение так часто встречается на практике — любой «суммарный» эффект множества независимых факторов стремится к нормальному.

// Применение
50 приборов, каждый регулируется U(4,10) мин. M=7, D=3. Суммарное время ~ N(350, √150)≈N(350, 12.25). Далее считаем как нормальное.
Связь с интегральной теоремой Муавра–Лапласа

Интегральная теорема Муавра–Лапласа — частный случай ЦПТ для индикаторов схемы Бернулли.

Индикатор i-го испытания: ξᵢ∈{0,1}, M=p, D=pq. Их сумма = число успехов ~ N(np, √(npq)).

ЦПТ (Центральная предельная теорема)
Сумма большого числа независимых одинаково распределённых СВ имеет распределение, близкое к нормальному.
Индикатор события
СВ принимающая 1 (событие произошло) или 0 (не произошло). M = p, D = pq.
ЦПТ — параметры суммы
ξ = Σᵢ ξᵢ ~ N(Σaᵢ, √(Σσᵢ²))
Одинаковые слагаемые: M = na, σ_суммы = σ√n.
Вероятность после применения ЦПТ
P(x₁ < ξ < x₂) = Φ((x₂-na)/(σ√n)) − Φ((x₁-na)/(σ√n))
// Лекция 06
Двумерные случайные величины
Совместный закон распределения, маргинальные законы, независимость компонент, корреляция.
Двумерная случайная величина (ξ, η)

Пара СВ, описывающих совместный результат опыта. Задаётся таблицей совместных вероятностей pᵢⱼ = P(ξ=xᵢ, η=yⱼ).

Сумма всех pᵢⱼ = 1.

Маргинальные (безусловные) законы

Закон распределения одной компоненты получается суммированием по всем значениям другой:

P(ξ=xᵢ) = Σⱼ pᵢⱼ   (сумма по строке)

P(η=yⱼ) = Σᵢ pᵢⱼ   (сумма по столбцу)

Условный закон и независимость

Условный закон ξ при η=yⱼ: P(ξ=xᵢ/η=yⱼ) = pᵢⱼ / P(η=yⱼ).

Независимость — условный закон совпадает с безусловным. Это равносильно: pᵢⱼ = P(ξ=xᵢ)·P(η=yⱼ) для всех i,j.

// Проверка независимости
Если хотя бы одно pᵢⱼ ≠ P(ξ=xᵢ)·P(η=yⱼ) — компоненты зависимы.
Непрерывная двумерная СВ

ФРВ: F(x,y) = P(ξ<x, η<y). Плотность: f(x,y) = ∂²F/∂x∂y.

P попадания в прямоугольник = разности значений F в углах (формула с 4 слагаемыми).

Совместный закон распределения
Перечень всех пар значений (xᵢ, yⱼ) и совместных вероятностей pᵢⱼ = P(ξ=xᵢ, η=yⱼ).
Маргинальный (безусловный) закон
Закон распределения одной компоненты, полученный суммированием по всем значениям другой.
Условный закон распределения
Закон распределения компоненты ξ при фиксированном значении η=yⱼ.
P(ξ=xᵢ|η=yⱼ) = pᵢⱼ / P(η=yⱼ)
Независимость компонент
Условный закон совпадает с безусловным: P(ξ=xᵢ|η=yⱼ)=P(ξ=xᵢ) для всех i,j.
pᵢⱼ = pᵢ · qⱼ
Маргинальные вероятности
P(ξ=xᵢ) = Σⱼ pᵢⱼ    P(η=yⱼ) = Σᵢ pᵢⱼ
Условная вероятность компоненты
P(ξ=xᵢ | η=yⱼ) = pᵢⱼ / P(η=yⱼ)
Критерий независимости
pᵢⱼ = P(ξ=xᵢ) · P(η=yⱼ) для всех i, j
ФРВ двумерной СВ — попадание в прямоугольник
P(x₁≤ξ≤x₂, y₁≤η≤y₂) = F(x₂,y₂) − F(x₁,y₂) − F(x₂,y₁) + F(x₁,y₁)
// Лекция 07
Математическая статистика. Выборочный метод
Генеральная и выборочная совокупность, выборочные характеристики, точечное и интервальное оценивание.
Выборочный метод

Генеральная совокупность (ГС) — весь изучаемый массив объёма N. Зачастую слишком велик для полного изучения.

Выборка — n объектов, извлечённых наугад. Должна быть репрезентативной.

Варианты записи: вариационный ряд (по возрастанию), статистический ряд (значение + частота), группированный ряд (интервалы при больших n).

Выборочные характеристики
  • Выборочное среднее X̄ = (Σxᵢmᵢ)/n — оценка M(ξ).
  • Выборочная дисперсия S² = Σmᵢ(xᵢ−X̄)²/n — смещённая оценка D(ξ).
  • Исправленная дисперсия s² = n·S²/(n-1) — несмещённая оценка D(ξ). Используй при оценивании!
// Важно
Делитель (n-1) вместо n делает дисперсию несмещённой оценкой генеральной дисперсии.
Точечное и интервальное оценивание

Точечная оценка — одно число (X̄ оценивает a, s² оценивает σ²).

Интервальная оценка (доверительный интервал) — интервал, покрывающий истинный параметр с вероятностью γ (доверительный уровень).

Для нормальной ГС с известным σ: доверительный интервал для a: X̄ ± ε, где ε = t·σ/√n. t находится из Φ(t) = γ/2.

При неизвестном σ: используют распределение Стьюдента с (n-1) степенями свободы.

Генеральная совокупность
Вся изучаемая группа объектов объёма N. Характеризуется параметрами a (МО) и σ² (дисперсия).
Выборка
Часть ГС из n объектов, выбранных случайно. Должна быть репрезентативной.
Вариационный ряд
Элементы выборки, упорядоченные по возрастанию: x₁≤x₂≤...≤xn.
Статистический ряд
Пары (xⱼ, mⱼ) — значение и его частота в выборке.
Репрезентативная выборка
Выборка, в которой пропорции значений схожи с ГС. Все условия одинаковы.
Несмещённая оценка
Оценка, математическое ожидание которой совпадает с истинным параметром.
Доверительный интервал
Интервал (X̄−ε, X̄+ε), покрывающий истинный параметр с вероятностью γ.
γ — доверительный уровень (0.9, 0.95, 0.99)
Выборочное среднее
X̄ = (1/n) Σ xᵢmᵢ = (1/n) Σ xᵢ
Выборочная дисперсия (смещённая)
S² = (1/n) Σ mᵢ(xᵢ−X̄)²
Исправленная дисперсия (несмещённая оценка)
s² = n·S² / (n−1)
Доверительный интервал для МО (σ известно)
X̄ − ε < a < X̄ + ε    ε = t·σ/√n
t из таблицы: Φ(t) = γ/2. При γ=0.95 → t≈1.96; при γ=0.99 → t≈2.576.
Размах выборки
R = x_max − x_min
// Лекция 08
Проверка статистических гипотез. Критерий Пирсона
Нулевая и альтернативная гипотезы, ошибки I и II рода, критерий χ² для проверки закона распределения.
Схема проверки гипотез

1. Выдвигаем нулевую H₀ и альтернативную H₁ гипотезы.

2. Выбираем критерий — числовую характеристику выборки (статистику).

3. Задаём уровень значимости α — допустимую вероятность ошибки I рода (0.05 или 0.01).

4. Находим критическое значение по таблице.

5. Если наблюдаемое значение попадает в критическую область W → H₀ отвергается. Иначе — принимается.

Ошибки I и II рода
  • Ошибка I рода (α) — отвергли правильную H₀. Вероятность = уровень значимости α.
  • Ошибка II рода (β) — приняли неправильную H₀ (H₁ верна, но отвергнута).
  • Мощность критерия = 1−β — вероятность правильно отвергнуть H₀.

Уменьшение α увеличивает β, и наоборот. Компромисс.

Критерий согласия Пирсона χ²

Проверяет, соответствует ли выборка предполагаемому закону распределения H₀.

Алгоритм:

  • Строим интервальный ряд (r интервалов).
  • Для каждого интервала: nᵢ — наблюдаемая частота, npᵢ — теоретическая.
  • Вычисляем χ²_набл = Σ(nᵢ−npᵢ)²/(npᵢ).
  • Находим χ²_крит по таблице с ν = r−1−k степенями свободы (k — число оцениваемых параметров).
  • Если χ²_набл < χ²_крит → H₀ принимается.
// Правило
В каждом интервале npᵢ ≥ 5. Если нет — объединяй соседние интервалы.
Нулевая гипотеза H₀
Проверяемая гипотеза (например, «закон нормальный» или «МО=35»).
Альтернативная гипотеза H₁
Гипотеза, принимаемая при отвержении H₀. Противоречит нулевой.
Критическая область W
Множество значений статистики, при которых H₀ отвергается.
Уровень значимости α
Вероятность ошибки I рода — отвергнуть верную H₀. Обычно 0.05 или 0.01.
Ошибка I рода
Отвергли правильную H₀. P(ошибка I) = α.
Ошибка II рода
Приняли неправильную H₀ (когда верна H₁). P(ошибка II) = β.
Мощность критерия
Вероятность правильно отвергнуть H₀. Чем выше — тем лучше критерий.
Мощность = 1 − β
Степени свободы ν
Для χ² Пирсона: ν = r − 1 − k. r — число интервалов, k — число оцениваемых параметров.
Наблюдаемое значение критерия Пирсона χ²
χ²_набл = Σᵢ (nᵢ − npᵢ)² / (npᵢ)
nᵢ — наблюдаемая частота, npᵢ — теоретическая частота для i-го интервала.
Степени свободы
ν = r − 1 − k
r — число интервалов, k — число параметров, оцениваемых из выборки. Для нормального: k=2 (a и σ).
Правило принятия/отвержения H₀
χ²_набл < χ²_крит(α, ν) → H₀ принять
χ²_крит берётся из таблицы по α и ν. Если χ²_набл ≥ χ²_крит → H₀ отвергнуть.
Ошибки и мощность
α = P₀(W)    β = P₁(O)    Мощность = 1−β
P₀ — при H₀ верна. P₁ — при H₁ верна.
